📁 INKAI — які файли залити

Як залити на GitHub (без папок):
1) відкрий репозиторій → папка assets → Add file → Upload files;
2) виділи й перетягни ВСІ свої файли разом (назви мають бути точно як нижче, малими літерами);
3) натисни Commit changes. За раз GitHub приймає до 100 файлів — решту заливай другою порцією.
Не знайшовся файл — гра сама покаже емодзі або синтезує звук, тож заливати можна поступово.
Ця сторінка перевіряє, що вже залито (відкривай її з сайту, а не з комп'ютера). Клік по назві — копіює її.
