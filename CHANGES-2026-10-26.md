# Зміни від 2026-10-26 (лише ці 2 файли відрізняються від inkai-release.zip)
- firestore.rules — claims: білий список id, серверний місяць (UTC), ts == час сервера, мини-тату 1 на акаунт за календарний місяць (спільно для покупки за монети й купона зі скрині), старі id uid_tat_coupon / uid_tat_mini рахуються в ліміт цього місяця, але нові з таким id заборонені; раффл-заявка лише за реальним призом у prizes; власник може читати свою заявку за id.
- social.js — купон сундука і покупка мини-тату пишуть один id uid_tat_mini_<місяць>; захист від подвійного натискання; повідомлення «вже подано» / «перевір дату на телефоні»; оновлено текст умов.
НЕ змінено: економіка, ймовірності сундуків (у т.ч. S.tatGot), правила нагород, версії ?v= (запусти bump.py при публікації).
Порядок публікації: 1) вставити firestore.rules у Firebase Console (замінити ADMIN_UID), 2) python3 bump.py НОВА_ВЕРСІЯ, 3) залити всі файли. НЕ перезаписуй свій робочий config.js файлом із цього архіву, якщо там уже стоять реальні ключі.
