# INKAI | Студия YYOKAI

Обновленный проект веб-игры INKAI в стиле японо-темного слэшера.

## Изменения в этой версии:
1. **Механика Сундука:** Открытие за 5 честных перекрестных свайпов из стороны в сторону (без авто-ударов зажатым пальцем).
2. **Обучение Slow-Mo Focus:** Всплывает без навязчивых плашек во время боя, плавно замедляя время.
3. **Градация Катан:** Легендарный ранг с золотым следом, эффектом Hitstop (остановка кадра) и кастомными звуками.
